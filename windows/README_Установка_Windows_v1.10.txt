УСТАНОВКА ЧЕРЕЗ АРХИВ ZIP
Извлеките архив AntiDPI_CLI_v1.10_Windows_x64.zip, откройте папку AntiDPI_CLI_v1.10_Windows_x64 и запустите УСТАНОВКА.cmd.
Подтвердите запуск от имени Администратора.
УСТАНОВКА ЧЕРЕЗ EXE
Двойным кликом запустите файл AntiDPI_CLI_v1.10_Windows_x64.exe.
Подтвердите запуск от имени Администратора.

Перед установкой остановите работающий AntiDPI/Zapret2, если он запущен. Для новой установки укажите пустую папку
(по умолчанию C:\AntiDPI). Чтобы обновить существующую AntiDPI, включите соответствующий флажок и укажите
папку установки: программа обновит только собственные неизменённые файлы, сохранив настройки, логи и папку Zapret2.
Файлы программы, изменённые пользователем, не перезаписываются. Другие непустые папки установщик не очищает.

Для новой установки можно выбрать один из вариантов официального Zapret2:
- закреплённая совместимая версия: SHA-256 архива сравнивается с заранее включённым манифестом (рекомендуется); доступны прямой и зеркальный маршруты;
- текущая ветка master: архив принимается только напрямую с codeload.github.com по HTTPS. Его SHA-256 записывается локально, но не сверяется с независимым доверенным значением; commit ID читается из архива и сам по себе не доказывает его происхождение. Выбирайте Latest, только если доверяете источнику и принимаете этот риск.

Можно включить создание ярлыков запуска/удаления. Индикатор показывает ход операции,
а «Открыть логи» — диагностические файлы. При новой установке загрузку можно отменить до проверки архива.
После проверки архив подготавливается к установке. При ошибке устраните указанную причину и нажмите «Повторить»;
логи сохраняются в профиле пользователя.

Официальный Zapret2 скачивается архивом исходного репозитория Bol-Van:
https://github.com/bol-van/zapret-win-bundle
Для закреплённой версии можно использовать GitHub или зеркало cdn.gh-proxy.org; в обоих случаях SHA-256 должен совпасть с манифестом.
Для Latest используется только прямая загрузка с GitHub по HTTPS, без стороннего зеркала.
Маршрут, commit и фактически вычисленный SHA-256 сохраняются локально; в Latest эти сведения не заменяют независимую подпись или заранее доверенную контрольную сумму.

Каждый 15-секундный интервал должен дать не меньше 3% полного объёма архива.
Если прирост меньше 3%, соединение закрывается, частичный файл отбрасывается и выполняется следующая попытка.
Загрузка завершается ошибкой после трёх попыток на источник или по истечении 10 минут.

Папка на Рабочем Столе AntiDPI содержит два ярлыка:
START_AntiDPI — запуск через ЗАПУСК_AntiDPI_Zapret2.cmd;
DELETE_AntiDPI — удаление через УДАЛИТЬ_AntiDPI_Zapret2.cmd.
В папку также копируются README_Установка_Windows_v1.10.txt и README_Стратегии_Windows_v1.10.txt.

Windows Firewall: автоматически создаётся одно исходящее разрешающее правило
только для полного пути <папка установки>\zapret-winws\winws2.exe.
Правило включено для всех профилей сети и протоколов и привязано к уникальному ID этой установки.
Повторная настройка не дублирует правило. Удаление программы удаляет созданное правило.
Разрешение Firewall не является антивирусным исключением и не отключает
проверку всех пакетов, которые проходят через WinDivert.

ПРЕДУПРЕЖДЕНИЯ ОБ АНТИВИРУСЕ
Установщик не отключает защиту Windows и не добавляет широкие исключения.
Если защитное ПО блокирует файл, проверьте сообщение и SHA-256 релизного архива;
не продолжайте установку, если сомневаетесь в источнике или обнаружении.
Windows Firewall получает только узкое исходящее правило для проверенного
winws2.exe этой установки. Это правило не меняет настройки антивируса.
Исключения для сторонних VPN-клиентов, если они вообще необходимы,
настраиваются отдельно по рекомендациям разработчика клиента.

ЗАМЕТКИ:
1. Стратегии разработаны специально для восстановления работоспособности VPN-конфигураций Черных Списков, Tor и YouTube.
2. Для работы с VPN Черных Списков или Tor включайте каждую стратегию поочередно, затем пингуйте подписки/мосты в вашем клиенте!
   На одних стратегиях будет больше живых VPN-конфигураций, на других меньше.
3. Вкладка «Анализ» последовательно проверяет указанные номера на доступность YouTube по IPv4/TCP/TLS
   и показывает результат каждой стратегии сразу после проверки. Анализ можно безопасно остановить.
4. Это только проверка доступа к YouTube. PASS не подтверждает работу VPN/Tor-клиента или туннеля,
   а FAIL не означает, что стратегия не подойдёт для VPN/Tor. Проверяйте свой клиент отдельно.
5. Стратегии Golden для VPN/Tor/Youtube могут работать лучше, чем Silver.
6. Набор стратегий протестирован на российских кабельных/мобильных сетях.

ЛОКАЛЬНЫЕ ИСКЛЮЧЕНИЯ IP
После установки IP-исключения находятся здесь:
<папка установки>\AntiDPI\lists\ips-exclude.txt (IPv4)
<папка установки>\AntiDPI\lists\ips6-exclude.txt (IPv6)

IPv4-список исключает локальные, link-local, multicast и CGNAT-подсети.
IPv6-список исключает unspecified/loopback, IPv4-mapped, documentation,
ULA, link-local и multicast адреса. IP-исключения запрещают применение стратегии
к перечисленным адресам; сохраняется штатный LAN-фильтр WinDivert.
Доменные исключения не используются.
После изменения IP-списка перезапустите активную стратегию.

АВТОМАТИЧЕСКОЕ ВОССТАНОВЛЕНИЕ WINDIVERT
Контроль запускается вместе с программой и действует во время работы стратегии и проверки YouTube.
При явной ошибке WinDivert или неожиданном завершении движка программа автоматически
пытается восстановить запуск той же стратегии с прежними адаптером и портами.
Журнал: <папка установки>\logs\WinDivert_recovery.log.

УПРАВЛЕНИЕ И АДАПТЕР В РАБОТАЮЩЕМ ОКНЕ
Все строки для управления и номер работающей стратегии выделены жёлтым:
СЕЙЧАС РАБОТАЕТ СТРАТЕГИЯ N!

ЧТОБЫ СМЕНИТЬ СТРАТЕГИЮ И ВЫБРАТЬ НОВУЮ - нажмите F1
ЧТОБЫ ПЕРЕЗАГРУЗИТЬ ТЕКУЩУЮ СТРАТЕГИЮ - нажмите F2
ЧТОБЫ СМЕНИТЬ СЕТЕВОЙ АДАПТЕР/ПОРТ - нажмите F3
ЧТОБЫ ПОЛНОСТЬЮ ОСТАНОВИТЬ РАБОТУ AntiDPI/ZAPRET2 - нажмите CTRL+C

F1: завершение текущего winws2.exe, выводится приглашение ввода нового
номера либо слова Youtube без повторного вывода таблицы стратегий; 0 — выход.
F2: завершение текущего winws2.exe и новый процесс с той же стратегией и тем же адаптером.
F3: завершение текущего winws2.exe, выбор из таблицы активных физических
IPv4-адаптеров с рекомендацией и выбором, сохранение по индексу GUID, новый процесс начнется с
той же стратегией. Нажатие Enter без ввода номера выбирает прошлый доступный адаптер.
Если он пропал, предлагается рекомендуемый. 
При обычной работе активна одна стратегия: перед выбором и повторным запуском старый процесс завершается.
F3 меняет адаптер обработки Zapret2; 
маршруты Windows и подключение самого VPN-клиента не меняются, существующие соединения на другой канал не переносятся.
Ctrl+C: остановка текущего winws2.exe и выход из программы.

Выбор адаптера. Enter использует прошлый выбор, если GUID (индекс) найден среди активных физических адаптеров. 
Выбор F3 сохраняется в AntiDPI\_state\adapter.json для следующего старта.

Далее выберите TCP-порты назначения, трафик которых будет перехватываться Zapret2.
Поддерживаются номер, диапазон, комбинации через запятую, all/все.
Enter в поле портов = все. Пример ввода: 80,443,1000-2000.

ПОДБОР СТРАТЕГИЙ ДЛЯ YOUTUBE
Вместо номера стратегии введите слово "Youtube" (регистр не важен).
Затем задайте номер одиночной стратегии или диапазон в формате Первая-Последняя, например 1-50.
После ввода укажите число одновременно проверяемых стратегий: от 1 до 5.
Проверка начинается только после явного ввода числа 1, 2, 3, 4 или 5.
Номер одиночной стратегии и оба конца диапазона должны существовать в выбранном каталоге; допустим и диапазон 3-3.
Пустой ввод, несуществующий номер и неверный диапазон не принимаются.

Перед проверкой обязательно выключите VPN/TUN. 

В GUI стратегии показываются списком с поиском по номеру/названию и фильтром семейств.
Вкладка «Анализ» сначала выполняет контрольный HTTPS-запрос без стратегии, привязанный к выбранному адаптеру, затем сравнивает выбранный диапазон стратегий.
Если контроль и стратегия успешны, результат будет BASELINE_PASS, а не PASS; при нестабильном контроле используется INCONCLUSIVE.
Во вкладке «Настройки» задаются семейство, транспорт и порты по умолчанию, диапазон и параметры YouTube-анализа, адаптер и показ подробных логов при ошибках. Версия и сведения о программе доступны на вкладке «О программе».
Проверка ограничена YouTube по IPv4/TCP/TLS и не подтверждает работу VPN/Tor-клиента или туннеля.
Для досрочной остановки нажмите «Остановить»; промежуточные результаты и диагностика сохраняются в логах.

ЛОГИ
Логи сохраняются в <папка установки>\logs:
AntiDPI_*.log — консольный лог установки, запуска или удаления;
winws2_*.log — вывод движка и проверки его параметров;
YouTube_*.log — объём, время, HTTP-статус, причина и результат каждой попытки;
YouTube_winws2_*.log — вывод движка во время подбора стратегий.
При неудаче до создания папки установки лог остаётся в %TEMP%\AntiDPI_Install_Logs.
Логи сохраняются после удаления программы для диагностики.

ЗАПУСК И УДАЛЕНИЕ
В папке на рабочем столе (ярлыки):
START_AntiDPI — открывает графическое окно управления стратегиями;
DELETE_AntiDPI — удаление с подтверждением УДАЛИТЬ или DELETE;

В корневой папке установки:
ЗАПУСК_AntiDPI_Zapret2.cmd — запуск графического окна управления;
УДАЛИТЬ_AntiDPI_Zapret2.cmd — удаление с подтверждением УДАЛИТЬ или DELETE.
В окне выберите IP-семейство (IPv4/IPv6), режим TCP + TLS ClientHello либо UDP + QUIC Initial, затем соответствующую стратегию, физический адаптер и порты назначения. Для TCP доступны 492 стратегии; для UDP — отдельные QUIC fake-профили (2 или 11 повторов). По умолчанию выбран порт 443. QUIC-режим обрабатывает только QUIC Initial, а не произвольный UDP. «all» для UDP охватывает весь UDP и может увеличить нагрузку. Кнопка «Остановить» запрашивает штатную остановку и восстановление состояния. Окно не проверяет VPN/Tor-туннель, авторизацию или работу стороннего клиента.
Удаляются исходные файлы и правило Windows Firewall.
Созданные ярлыки удаляются; папка на рабочем столе удаляется, если она пуста.
Изменённые/посторонние файлы сохраняются.
