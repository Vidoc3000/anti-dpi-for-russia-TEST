# AntiDPI — IPv4/IPv6, TCP/TLS и UDP/QUIC

**AntiDPI** — оболочка для закреплённого движка [Zapret2 от bol-van](https://github.com/bol-van/zapret2). Она позволяет выбрать IP-семейство и проверенную стратегию обработки TCP/TLS или UDP/QUIC Initial. Поддерживаются Windows 10/11 x64 и Ubuntu/Debian x64.

> AntiDPI меняет обработку выбранного трафика на устройстве. Это не VPN, прокси или Tor-клиент; программа не предоставляет туннель, учётные данные и доступ к подпискам.

## Что умеет программа

- Выбирать **IPv4 или IPv6** отдельно от выбора транспорта.
- В режиме **TCP/TLS** применять одну из **492 TLS-стратегий** к распознанному TLS ClientHello.
- В режиме **UDP/QUIC** использовать отдельные профили QUIC Initial: **#493** (`fake_default_quic` ×2) и **#494** (`fake_default_quic` ×11). Это не обычные TLS-рецепты и не обработка произвольного UDP.
- Ограничивать перехват выбранными портами. Для QUIC по умолчанию используется UDP/443; `all` охватывает весь UDP и может повысить нагрузку.
- На Linux использовать nftables/NFQUEUE, на Windows — штатный Windows-механизм перенаправления Zapret2.

Обрабатывается только выбранный транспорт, IP-семейство и диапазон портов. Остальной трафик не входит в область действия данной стратегии.

Запустите графический мастер установки от имени администратора. Для новой установки выберите пустую папку и источник Zapret2; для обновления укажите существующую установку — настройки, логи и папка Zapret2 сохраняются. Ход операции и логи доступны в окне мастера. Интерфейс адаптирован для компактных экранов; установщик ясно сообщает об успешном завершении. После установки откройте ярлык **AntiDPI**. GUI требует административных прав для запуска сетевого движка.

### Вкладки

- **Стратегии** — выбрать IPv4/IPv6, TCP/TLS или UDP/QUIC, стратегию, физический сетевой адаптер и порты; затем запустить или штатно остановить обработку. В списке адаптеров показываются имена устройств.
- **Анализ** — сравнивать стратегии с контрольными YouTube-запросами до и после серии; сравнительный режим выполняет пять проб в перемешанном порядке и показывает медиану/разброс времени, долю успехов и ориентировочный 95% интервал. Даже пять проб — малая выборка; стратегия не выбирается и не применяется автоматически. Результаты можно экспортировать в CSV.
- **Базовая матрица** — повторно проверять HTTPS и, если системный curl поддерживает, HTTP/3 для веб- и видеосервисов. HTTP-ответ с кодом вне 2xx/3xx показывается отдельно от сбоя соединения; матрица работает без стратегии и может быть отменена.
- **Проверка собственного узла** — ввести DNS-имя или IP, порт и необязательный SNI; отдельно проверить DNS, TCP connect и TLS handshake с проверкой сертификата, с привязкой к адресу выбранного адаптера. Отправляется только handshake, без HTTP/прикладных данных; адрес узла не попадает в локальную историю.
- **VPN/Tor** — отдельный маршрутный HTTPS-тест через выбранный интерфейс и Tor-проверка через локальный SOCKS5 с подтверждением Tor Project API. Они не смешиваются с прямыми пробами.
- **Проверка готовности** перед запуском, предложение профиля после стабильной смены сети, безопасное восстановление оставшегося движка после перезапуска GUI и просмотр списка файлов перед обновлением.
- **Настройки** — сохранить IP-семейство, режим TCP/TLS или UDP/QUIC, порты, диапазон и параллельность YouTube-анализа, предпочтение адаптера и режим без изменения TCP timestamps.
- Во вкладке «О программе» отображается версия и ссылка на релизы. В списке стратегий доступны фильтр по семействам, просмотр рецепта и аргументов движка, проверка параметров без запуска перехвата, список интерфейсов и управляемый перезапуск.

YouTube-анализ проверяет только прямую доступность YouTube по IPv4/TCP/TLS. VPN-тест привязывает запрос к выбранному интерфейсу, но не подтверждает скрытие IP, kill switch или отсутствие утечек; Tor-тест проверяет только ответ IsTor через локальный SOCKS5. Эти проверки не доказывают обход DPI, авторизацию или воспроизведение видео.

### Как выбрать стратегию

Начните с семейства **Golden** (обычно стратегии 1–45), затем сравните результаты на своей сети. Вкладка анализа помогает подобрать варианты для прямого доступа к YouTube, а не ранжирует их для всех VPN/Tor-сценариев. Результат может различаться в зависимости от провайдера, IP-семейства, приложения и порта.

Для известного сервера выберите его порт. Широкая область `all` может затрагивать больше соединений и повышать нагрузку. В режиме QUIC чаще всего достаточно UDP-порта 443.

## Linux CLI

Для установки распакуйте Linux TAR.GZ, перейдите в появившуюся папку и запустите установщик:

```bash
tar -xzf AntiDPI_CLI_v1.25_Linux_x64.tar.gz
cd AntiDPI_CLI_v1.25_Linux_x64
bash INSTALL.sh
```

Установщик подготовит приложение и ярлыки. Для сетевой обработки нужны системные зависимости и привилегии root; при штатном запуске AntiDPI запросит необходимые права. Запускать `INSTALL.sh` через `sudo` не требуется.

Примеры после установки:

```bash
antidpi list
sudo antidpi start --family ipv6 --protocol udp-quic --quic-profile fake2 --scope 443
sudo antidpi start --family ipv4 --protocol tcp-tls --strategy 1 --scope 443
sudo antidpi youtube                 # проверка YouTube: IPv4/TCP/TLS
sudo antidpi benchmark --target example.org:443
antidpi test --target example.org:443 --timeout 5 --json  # read-only DNS/TCP/TLS stages; no sudo by default
```

Поддерживаемые параметры можно посмотреть командой `antidpi --help`. Для диагностики окружения без изменения системных настроек используйте `antidpi doctor` или `antidpi doctor --json`; историю последних проверок — `antidpi history` (`--json` и `--limit 10` поддерживаются). Сетевые настройки можно сохранить и повторно запустить:

```bash
sudo antidpi profile save home --family ipv4 --protocol tcp-tls --interface eth0 --scope 443 --strategy 25
sudo antidpi profile list
sudo antidpi profile run home
sudo antidpi profile delete home
```

Профили сохраняются в каталоге состояния установки, а `profile run` запускает выбранную сеть с сохранёнными параметрами. Для переноса используйте версионированный JSON-bundle; импорт валидирует значения и по умолчанию отказывается перезаписывать совпадающие имена:

```bash
sudo antidpi profile export home --file "$HOME/home-profile.json"
sudo antidpi profile validate --file "$HOME/home-profile.json"
sudo antidpi profile import --file "$HOME/home-profile.json"
# Для явной замены совпадающих имён: sudo antidpi profile import --file "$HOME/home-profile.json" --replace
```

`sudo antidpi status --json` показывает принадлежащие установке таблицы, процессы движка и последнюю конфигурацию, не меняя систему. `sudo antidpi doctor --deep --json` дополнительно проверяет capabilities и выполняет только `nft --check` — правила не применяются. Benchmark делает два контрольных TLS-handshake без стратегии, затем сравнивает результаты тестируемых стратегий; для CSV или JSON используйте, например, `sudo antidpi benchmark --target example.org:443 --report-file "$HOME/benchmark.csv"`. В отчёте нет адреса или SNI узла, только случайный ID запуска, baseline, доля успехов и перцентили задержки.

Команда `test` по отдельности показывает DNS, TCP connect и TLS handshake; она не меняет правила сети и не отправляет HTTP- или прикладные данные. `--timeout` задаёт лимит TCP connect и TLS handshake (0,5–60 секунд); системный DNS-резолвер может занять дополнительное время. Привязка к интерфейсу через `--interface` может потребовать системных прав. Benchmark выполняет TLS/TCP handshake с заданным узлом; ни `test`, ни YouTube, ни benchmark не доказывают обход DPI, работу VPN/Tor-туннеля, авторизацию или передачу данных через сторонний VPN-клиент.

Для предварительной проверки нового релиза без установки и без прав администратора выполните `antidpi update --check`. Обычное применение обновления по-прежнему требует `sudo`.

Для обновления в версиях Linux, содержащих встроенный updater, установите актуальный официальный GitHub CLI (`gh`) и выполните `sudo antidpi update` (или `sudo bash <папка установки>/START.sh update`). Updater проверит SHA-256 и криптографическую provenance-attestation, требуя подпись именно workflow `.github/workflows/build.yml` репозитория проекта для ветки `main`; публичный Sigstore bundle получает без токена и передаёт установленному `gh` для локальной проверки. Если актуальный `gh` отсутствует или проверка не прошла, обновление будет остановлено. Его исполняемый файл и путь к нему должны принадлежать root и не быть доступны для записи группе/остальным. `--yes` не отключает эти проверки. Для обновления нужен исходящий HTTPS-доступ к GitHub и хосту `tmaproduction.blob.core.windows.net`, с которого GitHub отдаёт публичный подписанный bundle. Настройки и журналы сохраняются, предыдущая версия остаётся для отката командой `sudo bash <папка установки>/INSTALL.sh rollback --prefix <папка установки>`. Доступ к GitHub необходим; обновление собирает движок под текущую систему и может занять несколько минут. Локально изменённые файлы сохраняются в резервной копии, но автоматически в новую версию не переносятся.

### Проверка происхождения релизного пакета

Релизы, опубликованные workflow сборки, снабжаются GitHub artifact attestations для ZIP/EXE/TAR.GZ; перед публикацией workflow сам проверяет подписи и источник сборки. Для отдельной ручной проверки перед установкой скачайте официальный GitHub CLI (`gh`), при необходимости выполните `gh auth login`, затем запустите в каталоге с пакетом:

```sh
gh attestation verify ./AntiDPI_CLI_v1.25_Linux_x64.tar.gz --repo Vidoc3000/anti-dpi-for-russia-TEST --signer-workflow Vidoc3000/anti-dpi-for-russia-TEST/.github/workflows/build.yml --source-ref refs/heads/main --deny-self-hosted-runners
```

Подставьте имя скачанного файла, если версия или платформа отличаются. Команда должна завершиться успешно и подтвердить ожидаемый репозиторий, workflow и ref; при ошибке или отсутствии attestation не продолжайте установку, пока не проверите релиз. Затем дополнительно сверьте SHA-256 по `SHA256SUMS_*.txt`. Linux updater выполняет эту криптографическую проверку автоматически перед распаковкой пакета.

### Диагностический архив Linux

Для подготовки архива поддержки выполните `antidpi diagnostics --output "$HOME/antidpi-diagnostics.zip"`. CLI покажет список включаемых файлов и пример уже замаскированных данных; в интерактивном режиме можно исключить отдельные файлы и отменить создание. Частые учётные данные, IP-адреса, домены, интерфейсы и домашний путь маскируются автоматически. В неинтерактивном режиме требуется `--yes`, например `antidpi diagnostics --output "$HOME/antidpi-diagnostics.zip" --yes`. Результат создаётся с правами только владельцу. Автоматическая маскировка не гарантирует удаление всех персональных данных: перед отправкой откройте и проверьте архив.

Для штатного удаления запустите `DELETE.sh` из установленного комплекта. Чтобы удалить также сохранённые логи, папку установки и принадлежащие ей резервные копии обновления, используйте поддерживаемый установщиком режим полной очистки.

## Важные ограничения и безопасность

- **TLS-стратегии** применяются только к распознанному TLS ClientHello в TCP. Они не переписывают произвольный TCP-трафик.
- **QUIC-профили** работают с распознанными QUIC Initial в UDP на выбранных портах. Они не предназначены для любого UDP-протокола и не гарантируют совместимость со всеми QUIC-версиями и приложениями.
- **IPv4 и IPv6** выбираются явно; выбор одного семейства не включает другое.
- Тестовые статусы описывают конкретный пробник и его сетевые условия, а не универсальную «работоспособность» стратегии.
- Используйте программу только в сетях и на устройствах, где вы имеете право изменять обработку трафика. Перед широким охватом портов учитывайте возможную нагрузку.
