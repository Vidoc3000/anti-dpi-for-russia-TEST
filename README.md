# AntiDPI — IPv4/IPv6, TCP/TLS и UDP/QUIC

**AntiDPI** — оболочка для закреплённого движка [Zapret2 от bol-van](https://github.com/bol-van/zapret2). Она позволяет выбрать IP-семейство и проверенную стратегию обработки TCP/TLS или UDP/QUIC Initial. Поддерживаются Windows 10/11 x64 и Ubuntu/Debian x64.

> AntiDPI меняет обработку выбранного трафика на устройстве. Это не VPN, прокси или Tor-клиент; программа не предоставляет туннель, учётные данные и доступ к подпискам.

## Что умеет программа

- Выбирать **IPv4 или IPv6** отдельно от выбора транспорта.
- В режиме **TCP/TLS** применять одну из **492 TLS-стратегий** к распознанному TLS ClientHello.
- В режиме **UDP/QUIC** использовать отдельные профили QUIC Initial: **#493** (`fake_default_quic` ×2) и **#494** (`fake_default_quic` ×11). Это не обычные TLS-рецепты и не обработка произвольного UDP.
- Ограничивать перехват выбранными портами. Для QUIC по умолчанию используется UDP/443; `all` охватывает весь UDP и может повысить нагрузку.
- На Linux использовать nftables/NFQUEUE, на Windows — штатный Windows-механизм перенаправления Zapret2.

Обрабатывается только выбранный транспорт, IP-семейство и диапазон портов. Остальной трафик не входит в область действия данной стратегии.

## Windows GUI

Запустите графический мастер установки от имени администратора. Для новой установки выберите пустую папку и источник Zapret2; для обновления укажите существующую установку — настройки, логи и папка Zapret2 сохраняются. Ход операции и логи доступны в окне мастера. После установки откройте ярлык **AntiDPI**. GUI требует административных прав для запуска сетевого движка.

### Вкладки

- **Стратегии** — выбрать IPv4/IPv6, TCP/TLS или UDP/QUIC, стратегию, физический сетевой адаптер и порты; затем запустить или штатно остановить обработку. В списке адаптеров показываются имена устройств.
- **Анализ** — сравнивать выбранные стратегии с контрольным запросом без тестовой стратегии, настраивать параллельность, число попыток, HTTPS-таймаут и порог полученных данных. BASELINE_PASS означает, что YouTube прошёл и в контрольном запросе, поэтому эффект стратегии не подтверждён. Проверка ограничена YouTube по IPv4/TCP/TLS; она не доказывает работу VPN/Tor-туннеля или обход DPI.
- **Настройки** — сохранить IP-семейство, режим TCP/TLS или UDP/QUIC, порты, диапазон и параллельность YouTube-анализа, предпочтение адаптера и режим без изменения TCP timestamps.
- Во вкладке «О программе» отображается версия и ссылка на релизы. В списке стратегий доступны фильтр по семействам, просмотр рецепта и аргументов движка, проверка параметров без запуска перехвата, список интерфейсов и управляемый перезапуск.

Анализ YouTube **не проверяет VPN/Tor-туннель, конфигурацию, авторизацию или сторонний клиент**. Для оценки VPN/Tor выберите стратегию, включите её и проверьте соединение средствами своего клиента. Успешный YouTube-тест не означает, что эта стратегия лучше для VPN, и обратное тоже верно.

### Как выбрать стратегию

Начните с семейства **Golden** (обычно стратегии 1–45), затем сравните результаты на своей сети. Вкладка анализа помогает подобрать варианты для прямого доступа к YouTube, а не ранжирует их для всех VPN/Tor-сценариев. Результат может различаться в зависимости от провайдера, IP-семейства, приложения и порта.

Для известного сервера выберите его порт. Широкая область `all` может затрагивать больше соединений и повышать нагрузку. В режиме QUIC чаще всего достаточно UDP-порта 443.

## Linux CLI

Для установки распакуйте Linux TAR.GZ, перейдите в появившуюся папку и запустите установщик:

```bash
tar -xzf AntiDPI_CLI_v1.11_Linux_x64.tar.gz
cd AntiDPI_CLI_v1.11_Linux_x64
bash INSTALL.sh
```

Установщик подготовит приложение и ярлыки. Для сетевой обработки нужны системные зависимости и привилегии root; при штатном запуске AntiDPI запросит необходимые права. Запускать `INSTALL.sh` через `sudo` не требуется.

Примеры после установки:

```bash
antidpi list
sudo antidpi start --family ipv6 --protocol udp-quic --quic-profile fake2 --scope 443
sudo antidpi start --family ipv4 --protocol tcp-tls --strategy 1 --scope 443
sudo antidpi youtube                 # проверка YouTube: IPv4/TCP/TLS
sudo antidpi benchmark --target example.org:443
```

Поддерживаемые параметры можно посмотреть командой `antidpi --help`. Benchmark выполняет TLS/TCP handshake с заданным узлом; он не является проверкой VPN/Tor-туннеля. YouTube и benchmark не проверяют авторизацию или передачу данных через сторонний VPN-клиент.

Для штатного удаления запустите `DELETE.sh` из установленного комплекта. Чтобы удалить также сохранённые логи и папку установки, используйте поддерживаемый установщиком режим полной очистки.

## Важные ограничения и безопасность

- **TLS-стратегии** применяются только к распознанному TLS ClientHello в TCP. Они не переписывают произвольный TCP-трафик.
- **QUIC-профили** работают с распознанными QUIC Initial в UDP на выбранных портах. Они не предназначены для любого UDP-протокола и не гарантируют совместимость со всеми QUIC-версиями и приложениями.
- **IPv4 и IPv6** выбираются явно; выбор одного семейства не включает другое.
- Тестовые статусы описывают конкретный пробник и его сетевые условия, а не универсальную «работоспособность» стратегии.
- Используйте программу только в сетях и на устройствах, где вы имеете право изменять обработку трафика. Перед широким охватом портов учитывайте возможную нагрузку.
